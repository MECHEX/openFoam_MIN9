# V4b_3D run004c - BL Lout=16D outlet-sensitivity check

## Purpose

`run004c` is the controlled `Lout=16D` follow-up to `run004b` (`Lout=8D`).
The goal is not a new broad campaign; it is a short outlet-independence check
for the quantities that still shifted between `run003` and `run004b`:
`Cd_mean` and `Nu_EB_LMTD`.

## Setup Intent

| Parameter | Value |
|---|---:|
| Parent case | `/home/hexmachina/of_runs/V4b_3D_run004b` |
| Working case | `/home/hexmachina/of_runs/V4b_3D_run004c` |
| Re | 200 |
| Lin/D | 2.0 |
| Lout/D | 16.0 |
| Lx | 243.71 mm |
| Tube surface refinement | level `(2 2)` |
| Boundary layers | `hot_tube`: 8 requested, `hot_fin_z_min/z_max`: 6 requested |
| First layer | 30 um |
| Wake refinement | level 1, `x=0..72 mm`, `y=+/-12 mm` |
| Extra length vs run004b | coarse outlet buffer from 8D to 16D |

The wake refinement is intentionally kept the same as `run004b`, so the
comparison isolates outlet distance rather than changing near-wake resolution.

## Decision Criteria

If `run004c` matches `run004b` within a few percent for `Cd_mean`,
`Cl_rms`, `St`, and `Nu_EB_LMTD`, then `Lout=8D` is defensible as the
production domain. `run003` can then be described as qualitatively correct but
mildly outlet-sensitive for drag and heat-transfer metrics.

If `run004c` differs materially from `run004b`, then `Lout=8D` is not yet an
outlet-independent reference and the final domain choice must be revisited.

close for EB+LMTD heat transfer. This closes the main outlet-independence
question: `8D` is sufficient for production use, while `5D` is qualitatively
correct but mildly outlet-sensitive in drag and heat transfer.
