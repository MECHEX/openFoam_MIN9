# V4b_3D run006a - maxCo=0.4 timestep-sensitivity check

## Purpose

`run006a` is the first timestep/Courant sensitivity check for the accepted
production-domain candidate. It reuses the accepted `run004b` mesh and domain
(`Lin=2D`, `Lout=8D`) and changes only the adaptive timestep limit:

```text
run004b reference: maxCo = 0.8
run006a check:     maxCo = 0.4
```

## Decision Criteria

Compare against `run004b` using the matched late window `t = 3..6 s`.

| Quantity | Acceptance band |
|---|---:|
| Cd_mean | <= 1% |
| Cl_rms | <= 2-3% |
| St | <= 1% |
| Nu_EB | <= 1-2% |

If `run006a` matches `run004b`, keep `maxCo=0.8` for the longer production
run. If it differs materially, run a second check at `maxCo=0.2`.
